# Codex Autopilot v1.0.6

Lifecycle patch release for contract binding, worker-return orchestration, and
same-ticket repair lease reconciliation.

The release keeps schema `1.0` backward-compatible through optional attempt
provenance. It does not activate proposed contracts, reinterpret mixed legacy
bundles, release quarantined leases, or weaken readiness and ownership gates.

Verification requires the complete unit/qualification suite plus source/runtime
package parity after installation.
