## Правила, которые в этой сессии окупились

- **Worktree создаёт оркестратор** (`git worktree add`), не `isolation:"worktree"`
  инструмента Agent. Путь называется первой строкой промпта.
- **Блок границ копируется в промпт Codex дословно** — он не читает `AGENTS.md`.
- **Дозапрос идёт в ту же сессию** (`--resume-last`), эскалация — во
  **свежую** (`--fresh`): прежний тред может нести конструкцию, которая и
  даёт повторяющийся класс.
- **`BLOCKED` по дефекту контракта кругом ремонта не считается.**
- Ревьюеров ровно двое, постоянных; новых не заводить. Ремесленному давать
  путь `~/.agents/skills/autopilot/prompts/craft-review.md`.
- **Заявлению исполнителя «всё закрыто» веры нет.** Дважды подряд оно было
  ложным при зелёном прогоне. Проверяется прямым прогоном.

## Два урока этой сессии

**Шов доказательства нельзя держать в теле теста, названного про другое.**
Живая проверка суточного потолка обнаружения жила внутри теста с именем про
окно свежести. Окно сняли решением — вместе с ним молча ушло доказательство
потолка. Поведение осталось верным, доказательство исчезло, счётчик
пройденных тестов этого не показал.

**Семь находок из четырнадцати оказались пробелами контракта, а не промахами
исполнителей.** Повторяющийся класс «страж написан, но не сторожит» имел
источником двусмысленность, а не невнимательность: необязательный параметр,
значивший две несовместимые вещи (D23); протокол, не требовавший паспорта
(D24); поле, которого не было, при паспорте, который его требует (D19, D28);
строка паспорта «`raw_payload` — элемент целиком» рядом с разделом, этот
элемент запрещающим (D30) — она и породила критическую находку первого круга
таска 09. Прежде чем требовать третий круг, стоит перечитать контракт в том
месте, о котором спор.
