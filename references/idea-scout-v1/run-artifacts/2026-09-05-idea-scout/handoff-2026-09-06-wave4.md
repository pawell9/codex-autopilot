## Схема Claude → Codex (закреплена в AGENTS.md, раздел «Мост к Codex»)

- Claude Code — оркестратор: ведёт сборку, раздаёт таски, ревьюит, коммитит,
  пишет в `.autopilot/`. Codex — исполнитель: код в своей зоне, тесты, свои
  `docs/`.
- Мост — официальный плагин `openai-codex/codex`, подагент
  `codex:codex-rescue`. `--resume-last` продолжает тот же тред.
- **Базовая модель исполнителя — Terra High** (`.codex/config.toml`:
  `model = "gpt-5.6-terra"`, `model_reasoning_effort = "high"`).
- **Ремонт — в той же Codex-сессии** через дозапрос (`--resume-last`), не
  новой сессией.
- **Эскалация на Sol High** (`model = "gpt-5.6-sol"`) — только после **двух**
  кругов ремонта, провалившихся **по вине реализации**. Свежая сессия
  (`--fresh`, не `--resume-last`) — прежний тред может нести конструкцию,
  которая и дала повторяющийся класс дефекта (так было на таске 07).
- **`BLOCKED` по дефекту контракта не считается кругом ремонта.** Контракт
  правит оркестратор строкой D## в `manifest.md` и разделом в `interfaces.md`;
  исполнитель ждёт.
- **Astra — только по явному подтверждению пользователя** на конкретный
  запуск; сама по себе не берётся ни на исполнение, ни на ревью.
- **Worktree создаёт и удаляет только оркестратор**, `git worktree add`,
  **не через** `isolation: "worktree"` инструмента Agent — тот подчищает
  копию раньше, чем фоновый джоб Codex успевает написать код. Путь называется
  первой строкой промпта.
- **Одна рабочая копия — один исполнитель.** Параллель — через отдельные
  git-worktree, по одному на исполнителя.

## Границы ответственности

Codex пишет только внутри зоны своего тикета; не трогает `.autopilot/`,
`interfaces.md`, `manifest.md`, `spec.md`, `AGENTS.md`, `docs/executor.md`;
не делает `git commit`/`merge`/ветки; не создаёт и не удаляет worktree. При
выходе за зону или необходимости менять контракт возвращает `BLOCKED` с одной
строкой, чего не хватает — это правильное поведение, а не провал.

Границы копируются в каждый промпт кодекс-агенту дословно, первой строкой:

> Твоя зона: `<путь из тикета>`. Правила: пишешь только внутри зоны; не
> трогаешь `.autopilot/`, `interfaces.md`, `manifest.md`, `spec.md`,
> `AGENTS.md`, `docs/executor.md`; не делаешь `git commit`/`merge`/ветки; не
> создаёшь и не удаляешь worktree. Нужно выйти за зону или изменить контракт
> — верни `BLOCKED` с одной строкой, чего не хватает, и не исправляй это сам.

Потолок два дозапроса на тикет до эскалации. Держи двух постоянных
ревьюеров (манифест+спека и craft), передавай им таски по очереди, а не
создавай новых. Craft-ревьюеру давай путь
`~/.agents/skills/autopilot/prompts/craft-review.md`.

Реальные проверки (`pytest -m real`) прогоняй сам — исполнитель в песочнице
не имеет сети/авторизации, поэтому живой прогон обязателен именно от
оркестратора (на таске 06 и 07 живой прогон ловил то, чего не видели зелёные
тесты).
