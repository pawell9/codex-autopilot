## Что должно заработать

Список становится рабочим инструментом: статус ставится в один клик или в одну
клавишу, пишется мгновенно, переживает перезагрузку.

Статусы: новая / в избранном / отклонена / взята в работу. **Ставит их только
человек** — алгоритм не меняет ни одного.

**Но `in_work` — не обычный статус, и это главное в таске.** Обычный маршрут
меняет только `new` / `favorite` / `rejected`. `in_work` достигается **одной
операцией «создать проект»**: HTTP-обработчик зовёт готовый `scaffold` из
таска 14, дожидается результата и ставит статус **только при успешной записи
файлов**. Ошибка записи — статус не меняется и человек видит, что случилось.
Ошибка запуска редактора — проект остался, статус поставлен, показан путь.

Вся HTTP-часть перехода в проект принадлежит тебе: таск 14 сделал модуль,
не знающий про веб, а кнопку, токен, обработку исходов и отображение ошибок
делаешь ты.

Здесь же — ручной запуск исследования аналогов мимо порога: кнопка, которая
ставит работу `dossier` для выбранной идеи.

Клавиши: `j`/`k` — по строкам, `Enter` — досье, `f` — в избранное, `x` —
отклонить.

Сервер теперь умеет менять состояние, поэтому здесь же — защита: проверка
Host и Origin, изменение только не через GET, локальный непредсказуемый токен
на изменяющие запросы, без произвольного CORS. Аккаунтов при этом не заводится —
пользователь один.

## Критерии приёмки

- [ ] `new` / `favorite` / `rejected` ставятся кликом и клавишей, пишутся без перезагрузки страницы
- [ ] `in_work` **невозможно** поставить обычным статусным маршрутом — проверено тестом
- [ ] Переход «кнопка → HTTP → создание проекта → сохранение результата → статус» проходит целиком
- [ ] Ошибка записи файлов не ставит `in_work` и показывает причину; ошибка `code` оставляет созданный проект и ставит статус
- [ ] Два запроса с разными `op_id` для одной идеи не создают две папки — идемпотентность по идее, не по `op_id`
- [ ] Кнопка ручного исследования ставит работу `dossier` мимо порога
- [ ] Ни один код-путь, кроме действия человека, не меняет статус — проверено тестом
- [ ] Отклонённая идея не всплывает при повторном сборе и не удаляется из базы
- [ ] Изменяющий запрос без валидного локального токена отвергается
- [ ] Запрос с чужим Origin или Host отвергается — тест
- [ ] GET не меняет состояние — тест на всех маршрутах
- [ ] CORS не разрешён произвольным источникам
- [ ] Клавиши работают, фокус виден, `Enter` открывает досье
- [ ] Порция на разбор: верхние N неразобранных подаются первыми, остальные доступны фильтром
