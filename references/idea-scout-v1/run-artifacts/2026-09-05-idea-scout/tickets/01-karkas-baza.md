## Что должно заработать

Пустой проект превращается в устанавливаемый пакет с рабочей базой. Команда
`idea-scout init` создаёт SQLite-файл, применяет миграции и печатает, где он
лежит. `idea-scout --help` перечисляет команды (пока заглушки, кроме `init`).
Конфиг читается из `config/config.toml`, секреты — из `.env`, и ни одно
значение секрета не попадает в лог.

Схема и общие структуры уже согласованы — **не проектируй предметную модель
заново**. Всё, что нужно реализовать, дословно записано в `interfaces.md`:
§Общие структуры (датаклассы), §API хранения (сигнатуры `Store`),
§Подключение команд и обработчиков. Твоя работа — воплотить этот контракт,
а не придумать свой.

Отдельно: механизм подключения команд (`discover` по подпакетам) и `AppContext`.
Без них таски 07, 12 и 15 не смогут добавить свои команды, не залезая в чужую зону.

**`.env.example` пишешь только ты.** Таск 02 вернёт список имён переменных
в своём артефакте; впишет их сюда следующий владелец файла, а не он сам.

## Критерии приёмки

- [ ] `pip install -e ".[dev]"` ставит пакет, `idea-scout --help` работает
- [ ] `idea-scout init` создаёт базу и применяет миграции; повторный запуск не ломает существующую
- [ ] Миграции нумерованные, идут под блокировкой, проверяют текущую версию
- [ ] Включены внешние ключи, задан `busy_timeout`, режим журнала выбран и обоснован одной строкой
- [ ] В схеме нет и не может появиться операции удаления идеи — проверено тестом на публичном API `store`
- [ ] Четыре измерения состояния — четыре независимых поля, ни одно не выводится из другого
- [ ] Конфиг с отсутствующим `projects_root` даёт понятную ошибку, а не падение
- [ ] `.env.example` создан с пустыми значениями; реальный `.env` в `.gitignore`
- [ ] Все датаклассы из `interfaces.md` §Общие структуры существуют с теми же именами полей
- [ ] Все методы `Store` из §API хранения существуют с теми же сигнатурами; нереализованные явно поднимают `NotImplementedError`, а не молчат
- [ ] `store.tx()` — единственный способ открыть транзакцию; тест ловит попытку сетевого вызова внутри неё
- [ ] `discover` находит команду, положенную в `commands/`, без правки общего списка
- [ ] `AppContext` собирает config, store, budget, queue, llm_chain
- [ ] Версии зависимостей закреплены точными значениями, не диапазонами
- [ ] Тест: одновременная запись из двух соединений не роняет процесс
