## Что должно заработать

`idea-scout serve` поднимает локальный сервер на loopback, и в браузере
появляется плотный список идей — строками, как в Linear, а не плиткой.

В строке: название, суть в двух строках, тема, главная метрика с бейджем
доверия, уровень A/B/C, рынок первоисточника, возраст кейса, число блокеров.
Больше ничего — переизбыток в превью хуже, чем недостаток.

По клику сбоку открывается досье: метрики с доказательствами, аргументация по
осям, блокеры, аналоги в СНГ, все источники, снимок текста, если ссылка мертва.

Фильтры по уровню, теме, доверию, статусу, `scope`, архивности; сортировка по
скору и дате. Состояние фильтров — в URL.

Это read-only таск: кнопок, меняющих состояние, здесь ещё нет.

**Все данные приходят готовыми из `store`.** Суть карточки производит таск 08,
рынок первоисточника — код по правилу из `interfaces.md`, отчёт исследования —
таск 11 в замороженной структуре `ResearchReport`. Ты ничего из этого не
нормализуешь и не досчитываешь: нет данных — показывается честное «неизвестно»,
а не заглушка и не своя эвристика.

## Критерии приёмки

- [ ] `serve` слушает loopback; наружу порт не открыт
- [ ] Строка списка содержит ровно перечисленные поля и умещается в строку плюс две строки сути
- [ ] Досье открывается панелью сбоку, не отдельной страницей; грузится по запросу
- [ ] Ссылка на первоисточник кликабельна; допускаются только `http`/`https`
- [ ] Мёртвая ссылка → показывается сохранённый снимок текста
- [ ] Текст источника экранируется — тест с `<script>` и с `javascript:` в названии продукта
- [ ] Фильтры комбинируются, состояние в URL, перезагрузка страницы его сохраняет
- [ ] Тяжёлые проекты (`scope: team`) по умолчанию скрыты, доступны фильтром
- [ ] Архивные (старше 18 месяцев) по умолчанию внизу, доступны фильтром
- [ ] Серверная пагинация; десять тысяч карточек не выгружаются на одну страницу
- [ ] Панель состояния источников: работает / нет новых / частичный сбор / нужна настройка / ошибка / бюджет исчерпан + время последнего успеха
- [ ] Строка бюджета из `store.spend_summary`: потрачено / в резерве / осталось за период
- [ ] Отставание оценки: число работ в очереди и время последнего успеха; время повтора показывается **только если провайдер его сообщил**, иначе «неизвестно»
- [ ] Отчёт полезности источников за период из `store.source_usefulness`
- [ ] Идея без оценки видна как «не оценена», а не отсутствует в списке
- [ ] Подпись «предварительная оценка» на карточке
- [ ] Рынок первоисточника: бейдж, либо «неизвестно» — без догадок на стороне UI
- [ ] Мёртвая ссылка без снимка (снимок удалён политикой удержания) показывает «доказательство недоступно»
- [ ] Команда `serve` регистрируется механизмом таска 01
- [ ] Интерфейс по-русски; названия, цитаты и ссылки — в оригинале

## Поправка от 2026-09-06 — атрибуция видна, сигналы не выдаются за деньги

Часть источников MVP лицензирована так, что атрибуция обязательна: Stack
Exchange под CC BY-SA. Она обязана дойти до экрана, а не потеряться по дороге.

- [ ] Где источник требует атрибуции, карточка показывает автора, ссылку и лицензию — и в превью, и в досье
- [ ] `SignalObservation` показывается как сигнал со своим классом, **отдельно от денежных метрик** и без бейджа доверия, который принадлежит метрике
- [ ] Идея без денежных метрик, но с сигналами, читается честно: «денег не подтверждено, внедрение подтверждено трижды», а не пустое место и не выдуманная цифра
