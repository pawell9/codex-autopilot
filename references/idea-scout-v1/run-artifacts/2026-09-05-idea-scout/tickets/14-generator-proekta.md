## Что должно заработать

Модуль создаёт папку проекта и открывает её в VS Code. **Про HTTP он не знает
ничего** — кнопку, токен и обработку исходов делает таск 13, а ты даёшь ему
готовую операцию с раздельными исходами записи и открытия редактора.

Внутри создаваемого проекта: `AGENTS.md` (единственный источник правды), `CLAUDE.md` со ссылкой
`См. @AGENTS.md`, `.gitignore`, `docs/brief.md`, `docs/decisions.md`,
`.state.json`.

Всё собирается **детерминированными шаблонами** — ни одного вызова модели.

**Этот таск — про то, чего система делать не может.** Три операции:
`create_dir`, `write_new_file`, `open_editor`. Операций удаления и перемещения
в модуле нет — не «запрещены проверкой», а не написаны.

```python
def safe_path(root: Path, candidate: str) -> Path:
    if not candidate or Path(candidate).is_absolute():
        raise UnsafePath(candidate)
    if ".." in Path(candidate).parts:
        raise UnsafePath(candidate)
    p = (root / candidate).resolve()
    if not p.is_relative_to(root.resolve()):
        raise UnsafePath(candidate)
    return p
```

Досье уходит в `docs/brief.md` **внутри размеченного блока внешних данных** —
текст чужого поста не должен читаться следующим агентом как инструкция.
Доверенные части собираются только из шаблонов приложения.

## Критерии приёмки

- [ ] Три операции и ни одной больше; функций удаления и перемещения в модуле нет
- [ ] `safe_path` отвергает: пустую строку, абсолютный путь, `..`, симлинк наружу — по тесту на каждый
- [ ] Создание файлов не следует за симлинками
- [ ] Существующая папка не перезаписывается: ошибка плюс предложенное имя с суффиксом, решает человек
- [ ] Слаг папки — только `[a-z0-9-]`, ≤48 символов; вывод модели не становится путём или аргументом
- [ ] `code` ищется через `shutil.which`, запускается списком аргументов, `shell=False`; не найден → путь для копирования
- [ ] Идемпотентность **по идее**, а не по `op_id`: связь `idea_id → project_path` в `store`; повторный вызов с другим `op_id` возвращает тот же проект, а не создаёт второй
- [ ] Модуль не импортирует ничего из `web/` и тестируется на временной директории без HTTP
- [ ] Открытие редактора — отдельный исход; его неуспех не отменяет созданный проект
- [ ] Статус «взята в работу» **не** ставится при неуспешной записи файлов; частичная папка сохраняется с диагностикой
- [ ] `docs/brief.md` содержит задание на разработку и раздел незаполненных решений; досье — в размеченном блоке внешних данных
- [ ] `AGENTS.md` описывает, как переключаться между агентами вручную
- [ ] `.state.json` версии 1: цель, этап, сделано, следующий шаг, результаты проверок, блокеры, состояние рабочей копии
- [ ] **Проверено вручную на минимальном проекте, что структуру читают Claude Code, Codex и OpenCode** — не объявлено, а испытано
