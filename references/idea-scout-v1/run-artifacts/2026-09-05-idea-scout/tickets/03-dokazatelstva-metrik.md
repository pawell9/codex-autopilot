## Что должно заработать

Из текста поста или ответа API получаются отдельные утверждения о метриках,
каждое со своим доказательством и своим уровнем доверия. Годовая выручка не
превращается в месячную, цена продажи бизнеса — в выручку, число установок —
в MAU. Сумма без валюты или без периода остаётся неоднозначной и молча не
становится MRR.

```
MetricClaim: kind, value, unit_or_currency, period, observed_at,
             source_item_id, evidence_locator, evidence_excerpt,
             trust_level, extraction_method
```

Уровень доверия принадлежит **метрике и её периоду**, а не продукту: у одного
продукта могут быть подтверждённая выручка и заявленное число пользователей.

## Из брифа, дословно

> «которые имеют подтвержденные результативные показатели, такие как выручка, количество пользователей в месяц, то есть DAU, MAU»
> «То есть в зависимости от сервиса свои необходимые показатели»
> «Берём с уровнем доверия»

- [ ] `extract(item, mentions, llm)` возвращает список утверждений; ничего не найдено — пустой список, не выдуманное значение

- [ ] Сумма без валюты или без периода помечена неоднозначной и не принимается в поле метрики

## Уточнение второе — по блокеру `accept`

`accept(claims: list[tuple[int, MetricClaim]], idea_id: int) -> list[AcceptedMetric]`.
Пары «идентификатор плюс утверждение» — та же форма, что у `mentions`, одно
правило на весь модуль. `claim_id` приходит из `save_claims`, `idea_id` —
из `upsert_idea` (T04), и оба передаёт вызывающий, то есть конвейер T07.

Порядок в конвейере: `extract` → `save_claims` → резолв упоминаний в идею →
`accept(пары, idea_id)` → `save_accepted`.

**Правила доверия — твои, и живут в `accept`:** неоднозначное не принимается,
диапазон не принимается, цитата совпадает дословно. `store.save_accepted`
только записывает переданное и своей логики доверия не имеет — перенеси
проверки из `store.py` в `evidence`.

## Уточнение третье — потолок обращений к модели

`extract(item, mentions, llm, *, max_llm_calls: int = 3)` — именованный
аргумент со значением по умолчанию, сигнатура остаётся совместимой. Значение
передаёт вызывающий, то есть конвейер T07, взяв его из ключа
`evidence.max_llm_calls_per_item`. Ключ ты дописываешь в `config.py` сам —
зона расширена, **только дописывание**, ничего существующего не трогая.
Модуль `evidence` в конфиг не ходит и видеть его не должен.

Достижение потолка не проглатывается молча: `extract` пишет предупреждение
с идентификатором элемента и числом неразобранных фрагментов.

**Проверка связи «принятый факт ↔ идея» остаётся в `store.save_accepted`** —
решение подтверждено. Связь живёт в трёх таблицах, а `evidence` к базе не
ходит. Правила доверия при этом остаются в `evidence.accept`: это два разных
вопроса и две разные границы.
