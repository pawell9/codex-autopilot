## Что должно заработать

`Idea` — это **конкретный исходный продукт**, а не публикация о нём и не
абстрактная идея решения. Одна и та же находка из двух источников становится
вторым доказательством у одной идеи, а не второй карточкой. Два разных продукта
с похожими именами остаются разными.

Ошибочное слияние должно быть обратимым: сохраняются основание связи и исходные
элементы.

## Критерии приёмки

- [ ] Точное совпадение устойчивого ID источника или проверенного URL — автоприсоединение
- [ ] Домен — дополнительный сигнал; для общих платформ (gumroad, notion, github…) он не работает как идентификатор
- [ ] Нечёткое совпадение имени даёт **кандидата**, а не слияние
- [ ] Отказ пользователя (`rejected`) не переносится автоматически на нечёткого кандидата
- [ ] Сохраняются основание связи и исходные элементы; слияние можно откатить
- [ ] Неизвестный продукт сохраняется отдельным кандидатом, идентичность не угадывается
- [ ] Тест: одна публикация о двух продуктах; два продукта с одинаковым именем; повтор URL с разными параметрами
