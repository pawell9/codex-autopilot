# Записанные скиллы (Record & Replay)

Сюда падают скиллы, которые ты показал руками: Plugins → «+» → Record a skill → сделал в приложении → остановил запись → Codex написал черновик `SKILL.md` с условиями, входами, шагами и проверкой.

Требует Mac и включённого Computer Use. Правила записи: короткая законченная демонстрация · без секретов на экране · остановить сразу после результата · открыть черновик глазами и убрать лишние клики.

Первый скилл в этой папке — `[ЗАПИСАТЬ ДО СЪЁМКИ]`: выгрузка отчёта из внутренней панели в CSV. Пока папка пустая — запиши свой.
