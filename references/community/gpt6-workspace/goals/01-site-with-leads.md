# 01 · Сайт с формой заявок и базой — та самая цель из хука

## Результат
Одностраничный сайт `[НАЗВАНИЕ/ТЕМА]` с формой заявки (имя, контакт, сообщение) опубликован через `@Sites` и открывается по ссылке; отправленная заявка появляется в базе сайта и в таблице `leads`.

## Ограничения
- Стек: то, что `@Sites` собирает без сервера; база — встроенная база Sites.
- Дизайн: тёмный фон, один акцентный цвет, без стоковых картинок; тексты — из `goals/01-site-copy.md`, если файла нет — напиши сам, коротко, без «мы — команда профессионалов».
- Не подключать домен, не включать оплату, не отправлять письма.
- Время: до 3 часов.

## Проверка
- Открыть ссылку на телефоне — форма видна без прокрутки.
- Отправить тестовую заявку «Тест / test@example.com / проверка» — строка появилась в таблице.
- Повторная отправка пустой формы — ошибка валидации, а не запись.
- Готово, когда все три пункта пройдены; ссылка и скриншот таблицы — в отчёт.
