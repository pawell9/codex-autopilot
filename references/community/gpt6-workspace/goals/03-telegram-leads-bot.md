# 03 · Telegram-бот заявок

## Результат
Бот принимает заявку в три вопроса (что нужно, сроки, контакт), кладёт её в таблицу `leads` (Supabase через MCP или локальный SQLite, если доступа нет) и отвечает подтверждением; админ получает уведомление.

## Ограничения
- Стек: Python или Node — что уже есть в проекте; библиотека бота — одна, популярная, с версией.
- Токен бота — из переменной окружения `TELEGRAM_BOT_TOKEN`; если её нет — это развилка «доступы»: остановись и жди.
- Не деплоить; запуск локально.
- Время: до 3 часов.

## Проверка
- Тесты обработчиков зелёные.
- Ручной сценарий: три тестовые заявки — три строки в таблице, три подтверждения, три уведомления.
- Готово, когда сценарий пройден дважды подряд без правок кода.
