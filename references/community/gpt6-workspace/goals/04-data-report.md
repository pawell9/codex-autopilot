# 04 · Отчёт по данным

## Результат
Файл `reports/<дата>-report.md` по данным из `data/` (или пути, который дан): три вывода с числами, таблица до 10 строк, рекомендация одним абзацем; плюс схема через `@Visualize`, если сессия в приложении.

## Ограничения
- Использовать скилл `$report`.
- Не менять исходные данные; промежуточные файлы — только в `reports/tmp/`.
- Время: до 1 часа.

## Проверка
- Каждый вывод содержит число и сравнение с прошлым периодом.
- Таблица открывается, сортировка соответствует вопросу.
- Готово, когда отчёт умещается в один экран.
