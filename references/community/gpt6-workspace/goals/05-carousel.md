# 05 · Карусель по посту

## Результат
Пять слайдов 4×5 в папке `carousel/<дата>/` по тексту `posts/<файл>.md`, в одном стиле, текст читается на телефоне.

## Ограничения
- Использовать скилл `$carousel`; стиль по умолчанию, если в посте не указан другой.
- Не больше 8 генераций суммарно (5 слайдов + 3 перерисовки) — лимит картинок недельный.
- Время: до 30 минут.

## Проверка
- Пять файлов 1080×1350.
- Разбивка текста по слайдам лежит рядом в `slides.md`.
- Готово, когда ни один слайд не перерисовывался больше одного раза.
