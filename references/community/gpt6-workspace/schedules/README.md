# Расписания и триггеры

Расписания создаются только в приложении или вебе (Codex → Scheduled tasks), из терминала — нет. Здесь лежат тексты задач: открываешь файл, копируешь в поле задачи, ставишь расписание или триггер как указано в шапке. Выполняется локально или в отдельном worktree — выбирай worktree, чтобы не мешать дневной работе.

Правило лимита: задача раз в минуту сжигает окно за пару часов; раз в 15 минут — нормально.

| Файл | Тип | Когда |
|---|---|---|
| `morning-summary.md` | расписание | каждый день 09:00 |
| `trigger-mail-lead.md` | триггер Gmail | письмо с темой «Заявка» |
| `heartbeat-calls.md` | heartbeat | раз в 15 минут |
