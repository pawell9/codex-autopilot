# Записи звонков · heartbeat: раз в 15 минут · режим: worktree · профиль: work

Проверь папку `calls/` (путь можно поменять). Для каждого нового файла, которого нет в `calls/processed.md`:
1. Сделай транскрипт (если это аудио) и сохрани рядом `.md`.
2. Выпиши: кто звонил, что хочет, что обещали, сроки.
3. Собери черновик предложения клиенту по шаблону `calls/template-offer.md` (если файла нет — создай шаблон из трёх секций: задача, что сделаем, цена и сроки — и скажи мне об этом).
4. Добавь файл в `calls/processed.md`.
Ничего не отправляй — только черновики. Если новых файлов нет, заверши без сообщений в чат.
