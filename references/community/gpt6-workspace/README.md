# Рабочее место GPT-6 в Codex

Папка из ролика «GPT-6 Astra в Codex: 30 концептов за 40 минут». Всё, что в ролике настраивалось, здесь уже лежит файлами: три профиля с ревьюером, AGENTS.md с заметками между окнами, правила команд, хуки, три субагента, четыре скилла, тексты расписаний, пять готовых целей на ночь и таблица переезда с Claude Code. Шпаргалка всех тридцати концептов — [ШПАРГАЛКА.md](ШПАРГАЛКА.md).

## Установка — две команды

```bash
git clone <АДРЕС РЕПОЗИТОРИЯ> gpt6-workspace && cd gpt6-workspace
```
```bash
codex
```

При первом запуске Codex спросит, доверять ли папке — да: без этого не читаются `.codex/config.toml` и хуки. Затем `/hooks` — подтвердить три хука.

Идёшь с Claude Code — третья команда внутри сессии: `/import`. Твои скиллы и MCP лягут рядом с этими; что не переедет — в [MIGRATION.md](MIGRATION.md).

Правила команд Codex читает глобально, из `~/.codex/rules/` — один раз скопируй: `scripts/setup.sh` (старый файл сохранит в `.bak`).

## Три профиля

| Профиль | Для чего | Что включено |
|---|---|---|
| `codex --profile safe` | читать чужой код, разбираться | только чтение, спрашивает всегда, Medium |
| `codex` (work) | дневная работа | пишет в папку проекта, спрашивает по запросу, High |
| `codex --profile night` | ночная смена | пишет в папку, эскалации решает ревьюер Guardian, Max, запрет на `.env` |

Ночь запускается так: `codex --profile night` → `$night 01` (или своя цель одной строкой). Утром в чате — отчёт и ссылка. Первая цель — тот самый сайт с формой заявок из ролика: [goals/01-site-with-leads.md](goals/01-site-with-leads.md).

## Что в файлы не ложится — включаешь в аккаунте

- **Тон ответов** — Settings → Personalization: Friendly / Pragmatic / None.
- **Computer History** — Settings, только Mac, opt-in, требует включённой памяти.
- **Голос** — Ctrl+Shift+V в приложении; **питомцы** — Settings → Pets.
- **Расписания и триггеры** — только в приложении или вебе; тексты — в `schedules/`.
- **Плагины и коннекторы** — вкладка Plugins и `/apps`: Gmail, Notion, Netlify, Apple Messages подключаются в один клик; MCP в `config.toml` — для сервисов вне каталога.

## Как давать контекст

Окно любого приложения — в чат: обе клавиши Command (Mac). Приходит не картинка, а текст окна, включая то, что за прокруткой. Открыт макет — сверстал; открыто письмо — ответил; открыта ошибка — починил. Google Docs и Gmail в браузере отдают только видимую часть.

## Проверить на своей версии

В файлах стоят пометки `[ПРОВЕРИТЬ]` — это места, где документация не даёт точного синтаксиса или он мог поменяться. Перед первой ночью:

1. `codex update` → `/model` — имя модели по умолчанию; поправь `model` в `config.toml`.
2. `codex --profile night` → `/permissions` и `/status` — профиль подхватил песочницу, одобрения, ревьюера и права.
3. `codex execpolicy check` — синтаксис `rules/default.rules`.
4. `/hooks` — три хука видны и подтверждены; `codex features` — `memories`, `context_management`.
5. `$night 05` днём, на 30 минут — отчёт пришёл по шаблону, ссылка на снимок чата открывается.
6. `$heal night 3 --inputs goals/` — скилл починил себя по первым прогонам.
