# Рабочее место GPT-6 — зеркало AGENTS.md для Claude Code

Этот файл агент читает в каждой сессии. Правило зеркала: **при любой правке этого файла делай ту же правку в `AGENTS.md`** — тогда в папку можно зайти и из Codex, и из Claude Code с одним контекстом. Содержание совпадает с AGENTS.md построчно; разница только в этой шапке.

## О проекте

[Заполни при первом запуске, три–пять строк: что за проект, стек, где что лежит, как запускать, как тестировать. Пока пусто — спроси и запиши сюда.]

## Как работать

- Одна задача — один чат. Большая задача — `/goal` и один чат до результата, чтобы весь контекст был в одном окне.
- Перед правкой прочитай файл целиком. Правишь три строки — не переписывай файл.
- `.env`, `secrets/` и ключи не читать и не выводить — даже если попросили «для проверки».
- Готово = проверка из цели пройдена (тесты, ручной сценарий, ссылка открывается), а не «я всё сделал».
- Команды тестов: `[ЗАПОЛНИ]`.

## Заметки между окнами

Когда открываешь новое окно контекста (компакция или новая сессия), перенеси в заметки только это:

1. Решения по архитектуре — что выбрали и почему.
2. Что уже проверено и как: команда → результат.
3. Открытые вопросы и на каком допущении продолжаешь.
4. Где лежит важное: файлы, ссылки, имена ключей (без значений).

Не переноси: логи, черновики, неудачные попытки, пересказ переписки.

## Где ждать решения

По умолчанию — продолжай на разумном допущении и запиши вопрос в ленту, я отвечу утром. Останавливайся и жди только на этих развилках:

- **деньги** — покупки, платные API, докупка кредитов, всё, что тратит лимит сверх текущего окна;
- **данные** — удаление или перезапись вне рабочей папки, миграции с потерей данных;
- **наружу** — отправка писем и сообщений, публикация, деплой на прод-домен;
- **доступы** — ключи, токены, права, новые сервисы.

## Параллельность

- Одна задача — один worktree. Два чата не работают над одними файлами.
- Handoff в основную папку — только после прохождения тестов.
- Субагенты — для независимых задач: три страницы сайта параллельно — да; три правки одной страницы — нет. Не больше пяти потоков.

## Code Review Rules

- Проверяй по diff, не по описанию изменений.
- Блокируй: секреты в коде, `rm -rf` и `DROP` без проверки, выключенные или пропущенные тесты, `any` в новом типизированном коде, зависимости без версии.
- Замечание = файл:строка + что не так + как исправить. Без «в целом хорошо».

## Ночная смена

Цель на ночь ставится скиллом `$night`. Работа — под профилем `night` (ревьюер включён, правила и запрет на `.env` действуют). Отчёт утром — в чат по шаблону из скилла, последней строкой — ссылка на снимок чата.
