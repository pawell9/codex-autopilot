# Переезд с Claude Code — что переезжает, что нет и что делать руками

`/import` в Codex (0.145.0+; в приложении — Settings → Import) находит Claude Code на компьютере и переносит сам. Не работает во время идущей задачи и в удалённой сессии. Обратного пути нет.

| Что | Как переезжает | Куда | Что делать руками |
|---|---|---|---|
| CLAUDE.md | как есть → AGENTS.md | корень проекта | открыть глазами; лимит 32 КиБ — длинное обрежется; добавить `## Code Review Rules`; оставить строку-зеркало, чтобы CLAUDE.md жил рядом |
| settings.json | как есть → config.toml | `~/.codex/config.toml` | сверить с `.codex/config.toml` этого рабочего места: профили, права, сеть в settings.json не было |
| Слэш-команды `.claude/commands/` | становятся скиллами | `.agents/skills/<имя>/SKILL.md` | вызов теперь `$имя`, не `/имя`; `/prompts:` устарели |
| Скиллы `.claude/skills/` | как есть | `.agents/skills/` | ничего; формат SKILL.md общий |
| Плагины | как есть | каталог Codex | проверить, что плагин есть в каталоге; коннекторы ChatGPT — подключить заново одним кликом |
| MCP-серверы `.mcp.json` | как есть | `[mcp_servers.*]` в config.toml | ключи — в переменные окружения; `codex mcp login` для OAuth |
| Память (auto memory) | переносится | `~/.codex/memories/` | включить `[features] memories = true` — по умолчанию выключена |
| Субагенты `.claude/agents/*.md` | переносятся | `.codex/agents/*.toml` | сверить роли; потолок 6 потоков, один уровень; Agent Teams нет — параллельность через `codex agents`, `codex queue`, `@задача` в чате |
| Хуки | **с потерями** | `hooks.json` | 12 событий вместо 30+; обработчик — только `command` или `mcp_tool`; хуки с обработчиком-промптом или агентом — переписать в команду или убрать; доверие каждому — `/hooks` |
| Чаты | до 50 за 30 дней | история Codex | ничего |
| `/rewind` | **не переезжает** | — | форк от любого сообщения (правый клик → Fork) |
| Worktree из CLI | **с потерями** | приложение и IDE | флага в CLI нет; режим Worktree выбирается при создании чата |
| Каналы Telegram | **не переезжают** | — | заявки из Telegram заводить через MCP или бота; Codex Remote — для управления с телефона |
| Хуки-промпты, Agent Teams, `/rewind`, Telegram | — | — | это и есть список «руками»; всё остальное — одна команда |
